# Focused Task v1.16.0 (versionCode 27)

Issue: #57 · PR: #60 · Date: 2026-11-20

v1.15.1 (#56, PR #59) was merged but not released on its own; this release ships it too, so the "What's new" texts cover both.

## Upload to Google Play
- App bundle: `focused_task-1.16.0.aab` (from `flutter build appbundle --release`)
- Release name: `1.16.0 (27)`
- Store listing changed: no

### What's new – en-US
• The category board shows how far each category is: a ring fills as you complete its tasks.
• See how much time you spent on each category today, right in its header.
• The keyboard now closes when you tap outside a text field, so Save is never hidden after adding sub-tasks. There's also a Save button at the top of the task form.

### What's new – de-DE
• Das Kategorie-Board zeigt, wie weit jede Kategorie ist: Ein Ring füllt sich, während du ihre Aufgaben erledigst.
• Sieh direkt im Kopf jeder Kategorie, wie viel Zeit du heute dafür aufgewendet hast.
• Die Tastatur schließt sich jetzt, wenn du neben ein Textfeld tippst – Speichern bleibt nach dem Anlegen von Unteraufgaben erreichbar. Dazu gibt es oben im Aufgabenformular einen Speichern-Button.

## GitHub Release notes

### Added
- **Category board**: every category shows a completion ring in its colour ("2 of 5 tasks done (40%)" as tooltip, a check mark when all are done) and the time tracked on its tasks that day (`HH:MM`). (#57)

### Also in this release (v1.15.1, not released separately)

#### Added
- A *Save* button (check mark) in the task form's app bar, reachable while the keyboard is open. (#56)

#### Fixed
- Tapping outside a text field now closes the on-screen keyboard everywhere in the app (task form, sub-tasks, duration, categories, focus mode). Before, after adding sub-tasks the keyboard stayed open and covered the *Save* button. (#56)
- Scrolling the task form or focus mode closes the keyboard. (#56)
